# Развёртывание «Элемент Арно» на Vercel

Сайт готов к раздаче из `dist/`. В корне проекта лежит `vercel.json`, который задаёт параметры для Vercel. Точка входа сайта — `dist/index.html`.

## Настройки существующего проекта

В Vercel откройте проект и перейдите в **Settings → Build and Deployment**.

| Поле | Значение |
| --- | --- |
| Git Repository | `nikitaalimov892-spec/-` |
| Root Directory | Корень репозитория (`./`, значение по умолчанию) |
| Framework Preset | `Other` |
| Build Command | Включить **Override** и полностью очистить поле |
| Install Command | Включить **Override** и полностью очистить поле |
| Output Directory | `dist` |
| Environment Variables | Для сайта дополнительные переменные не требуются |
| Production Branch | `main` |
| Ветка для Preview Deployment | `site-preview` |

Пустые поля команд оставьте без пробелов и кавычек. В частности, очистите прежнюю команду `python3 build.py`. В проверенной ветке GitHub `main` на коммите `32ba714` в корне были только `README.md` и каталог `dist/`. Попытка открыть `/vercel/path0/build.py` из такого checkout завершалась ошибкой отсутствующего файла.

## Открыть рабочую версию в Chrome

1. Сохраните настройки Vercel. Проверьте, что интеграция Git подключена к указанному репозиторию, а `main` выбрана для окружения **Production**.
2. После отправки ветки `site-preview` Vercel создаст для неё **Preview Deployment**. На вкладке **Deployments** выберите запись с этой веткой и хешем отправленного коммита. Если автоматический запуск в проекте отключён, используйте **Create Deployment** и укажите эту ветку или коммит.
3. Дождитесь статуса **Ready**, нажмите **Visit** и откройте выданный HTTPS-адрес в Chrome. При включённой Deployment Protection войдите в учётную запись Vercel с доступом к проекту.
4. У отдельного deployment есть адрес конкретной версии. Для просмотра дальнейших изменений используйте адрес ветки из раздела **Domains** соответствующего deployment. Он будет указывать на последнюю успешно развёрнутую версию этой ветки.

Проверьте первый экран, ссылку «Смотреть кейс», карточки услуг, меню и FAQ. На телефоне проверьте открытие набора номера и Telegram.
